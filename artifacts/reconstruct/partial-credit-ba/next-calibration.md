# Required calibration before selecting a clue policy

Keep BA's prompts, scores and bins frozen. Its raw histogram is a diagnostic, not a distribution to optimize by relabeling.

1. Add an equivalence control pair: in S_100, “exactly one cycle of length at least51” and “at least one cycle of length at least51” are equivalent because two such cycles cannot fit. Require P4/T4 for the pair.
2. Contrast three errors with the same objects: asking for a supplied count (tautological question), asking for N given the count (substantive inverse-target error), and asking for a count with an unresolved N (underdetermined question). Only the first warrants the answer-copy override; the others retain dimension-based credit.
3. Contrast copying the supplied answer in the justification with stating the requested answer in the question. Unsupported/circular verification earns low M; it should not by itself erase P/T/E. Add matched positive and negative fixtures rather than a blanket prohibition on using the answer for inference.
4. Calibrate target fidelity independently of missing premises. A missing parameter is a premise error; any target deduction must identify an actual change in the requested quantity/event, not merely repeat the premise penalty.
5. Freeze revised judges after review against manually labeled development fixtures, then evaluate fresh fixture cases. Report shortcut false positives, equivalence errors and dimension agreement, not only mean-score agreement.
6. Only then generate fresh PC-v1 responses under the fixed exposure policies. Use paired source families to compare policies and reserve fresh families for confirmation. Preserve rejected inputs, missing outputs and invalid reconstructions in coverage accounting.

Selection must prioritize valid inputs, reliable grading and grounded semantic recovery. The desired middle-heavy shape is a secondary descriptive target; do not change bins or cherry-pick sources to achieve it. Report the observed histogram even if it remains polarized. Six repeated source families cannot validate a population shape, and a mean in20–75/100 does not establish useful partial credit.
