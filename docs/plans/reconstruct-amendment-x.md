## Observed problem

W source46's public reviewer rejects because answer560 and the multinomial relation permit inverse inference of omitted column heights. The source-aware reviewer accepts precisely because those essential heights must be inferred. The converter's positive rectangle demonstration likewise withholds an essential numerical premise inferred using the supplied answer. The scientific question is whether the rubric consistently distinguishes **disclosing a source premise** from **using the answer to infer a missing source premise**. Unique recoverability is not itself evidence of copying. Conversely, an omitted word or arithmetic spelling of an already exposed value does not create a substantive missing premise. Difficulty of the inverse calculation and direct disclosure should be measured separately.

## Candidate clarification and controls

Retain the bans on copied/paraphrased questions, complete premise-target bundles, and complete/nearly complete forward solutions. Clarify that a genuinely missing essential parameter inferred using the final answer can be a valid inverse task even when the algebra is elementary. This does not automatically admit the input: the parameter must not be supplied equivalently elsewhere, a full forward derivation must not be visible, and source support must hold. A forward arithmetic expression whose operands are all public is an exposed value; replacing an unknown premise by solving a constraint involving the answer is an inverse inference.

1. Full premise-target bundle: reject.

3. Essential premise absent, requiring an answer-conditioned inverse calculation: potentially acceptable under the proposed clarification, with explicit calculation and no full forward solution.
4. Essential premise formally absent but a complete/nearly complete forward solution supplied: reject.

Keep the original source and answer fixed within each family. Verify every numerical reference exactly. Avoid reusing any confirmation source.
