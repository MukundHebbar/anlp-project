## Task and capability

Given a final answer A and a few supported observations C, infer a plausible original mathematical question Q′ and supply a short verification J connecting Q′, C and A. This tests abductive reasoning under incomplete evidence, followed by mathematical checking. Sparse evidence need not uniquely identify the original. A sound alternative can receive quality credit while failing original-question recovery.

The current endpoint requires Q′ to state its necessary premises and requested quantity. Mathematical reparameterizations and equivalent formulations count; exact words and variable names do not matter. Asking for a different unknown does not count merely because the verification recovers an original parameter. The question's answer must actually be A. Context-dependent questions are reported separately while the user's preference on that boundary remains unresolved; historical standalone labels remain unchanged.

Only SOLVE, JUDGE and RECONSTRUCT enter the later transfer study. Prompt calibration is not evidence of training transfer.

## Fixed generation and exposure procedure

1. Allocate sources before looking at student outcomes. Check question, answer and reference mathematics. Record ambiguities and invalid sources in the allocated denominator; do not silently replace them.
2. Run one frozen few-shot converter on every valid source. Keep the exact source and prompt hashes. Generate supported natural-language observations, private support references, and a private account of what remains to infer. Private fields never enter the student prompt.
3. Apply one exposure rule globally. The latest tested rule uses `convert_p9_missing_target`, a bank of3–5 observations, and the first3 unchanged sentences. The parser ceiling must be6 and the separately registered generator bounds3–5. This rule is an **experimental baseline**, not an optimal or validated selection. More words, more clues and more information are distinct variables.
4. Audit the exact combined public answer and clues for mathematical support, direct question disclosure, complete-solution disclosure and a copy-only shortcut. A shorter exposure needs its own audit. Its parent's private certificate does not establish identifiability. Preserve disagreements and exact counterexamples; unresolved items do not pass.

**2026-09-24 protocol change, user-directed: audit + correct (dataset v1.1).** Sources that the dual gate does not accept now get one audit-and-correct pass ([`audit_correct_p1.md`](../../../data/prompts/reconstruct/runtime/audit_correct_p1.md), stages `realtime-correct` → `realtime-verify` → `collect-correct` in `scripts/generate_reconstruct_dataset_v1.py`). The agent sees the source, the reference solution, the four public clues, the two unused bank clues, and the v1 audit and copy-challenge outputs. It returns `ACCEPT_UNCHANGED`, `UNREPAIRABLE`, or `CORRECTED` with exactly four clues. Clues it judges sound must be kept verbatim, and at least one clue must change. There is one pass per source with no loop, and no student output enters any stage. The first design followed [amendment R](../../plans/reconstruct-amendment-r.md): a corrected set would count only if a fresh `final_v1` audit and copy challenge passed it, and `ACCEPT_UNCHANGED` would not overturn a v1 rejection. At the user's direction, to limit cost, the pipeline is now **two steps: generation, then audit + correct, whose decision is final**. There is no copy challenge and no re-verification, so the corrector effectively certifies its own fix, and 751 v1-rejected sources were accepted unchanged. Fresh checks that had already run on corrected sets are kept as advisory fields only: 510 passed, 443 were rejected, 322 have no verdict. Each v1.1 row records its acceptance route so any subset can be excluded. The prompt was piloted on 40 train-split sources only and then applied unchanged. The pilot rescued 9/40. Of four rescued cases read against their sources, three withheld a genuine essential element (a summation limit, a denominator, a question target). One added a solution hint ("examine the expression modulo 3") that the fresh audit still accepted. Corrected clues therefore carry the same fallibility as v1 gate decisions and need the same human audit before training use. v1.1 rows keep `original_public_input`, the corrector's findings, and both verification verdicts.

The leakage boundary is substantive: copying or paraphrasing a complete question is disallowed, as is giving the whole derivation. An inferred missing premise or target may be legitimate. Ordinary words, necessary symbols and shared domain facts are not automatically leakage. Lexical overlap alone cannot decide the boundary. The existing copy challenge's treatment of target selection still needs independent calibration; no final automated leakage-accuracy claim is supported.

## Endpoints and ratings

Report these separately for every version:

- Quality score: stored0–4, displayed1–5 by adding1, normalized0–100 by multiplying stored score by25. Display1 is no usable/copy-only output;2 is a substantive but demonstrably invalid attempt;3 is plausible with an essential unverified connection;4 is valid with an incomplete verification;5 is fully grounded. Never alter these meanings to shape a histogram.
- Semantic recovery: the reconstructed question represents the original mathematical task, up to equivalence. Same final number alone is insufficient.
- Grounded semantic recovery: semantic recovery plus a correct answer, coherent clue grounding, sound verification and valid non-leaking input. Preserve assistant review, teacher labels and independent human labels as distinct provenance.
- Conversion coverage, audit rejection/abstention, malformed outputs and missing judgments. Missing scores are not automatically displayed1. Report available-case statistics and planned-slot bounds.

The quality judge is source-blind. The equivalence judge sees the source separately. A correctness veto does not rewrite a raw quality score; report disagreements. A single model acting as converter and judge is not independent validation.

## Selection and stopping rules

On development data, seek mean20–75/100, semantic recovery20–40%, and a naturally middle-heavy five-level histogram:3 the mode,2/4 more common than their adjacent extremes1/5. This is a difficulty-design objective, not a quota. A five-category ordinal distribution need not be Gaussian. Small samples cannot establish a population shape.

Prioritize valid inputs and reliable measurement before optimizing difficulty. If wrong targets dominate, test a globally specified target/premise exposure rule. If false mathematics dominates both direct SOLVE and RECONSTRUCT, examine source difficulty and model capability. If direct SOLVE succeeds but reconstruction fails, use matched elementary controls to isolate inversion and target selection. If judge fields conflict or correct conclusions hide false proofs, calibrate the judge before selecting a generator. Change one factor where feasible, register any necessary bundle, keep all allocated cases, and record each decision and negative result.

Freeze the complete generator, prompts, sampling, judges, thresholds, source-family allocation and analysis before fresh confirmation. Require at least5/25 preallocated families to yield grounded semantic success; report the20–40% semantic target separately. Five successes alone are a pilot gate, not precise proof of a population rate. Do not tune on confirmation and still call it held out. A failed gate means the candidate is not released.

Near-perfect teacher accuracy requires independent labeled validation with false accepts, false rejects and abstentions reported. Passing a small authored calibration set is insufficient. No deadline or target score guarantees these empirical conditions can be met.
